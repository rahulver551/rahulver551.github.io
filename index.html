Research direction

Computer vision, multimodal, agentic, and distributed intelligence.

I am interested in visual models that learn from incomplete supervision, multimodal systems that connect images, audio, language, graphs, and sensor evidence, agents that reason and use tools without losing provenance, and distributed learning systems that operate under privacy, latency, memory, and communication constraints.

At IIT Madras, I designed a federated learning framework for VNF auto-scaling using LSTM/GRU forecasting and Time-GAN synthetic telemetry, and developed a federated deep-learning system for dynamic VNF placement across multi-cloud environments without sharing raw operator data.

Experience & selected projects

Cisco Systems

Agentic systems, network intelligence, engineering AI, and edge platforms.

01

AgenticOps: Autonomous Network Reasoning

Designed monitoring, diagnostic, verification, and remediation agents coordinated by state machines and causal Graph RAG over topology, telemetry, logs, configurations, and incidents. Added policy checks, confidence thresholds, human approval, rollback, and post-action verification; reduced targeted diagnosis from approximately 60 minutes to 5 minutes and active token overhead by more than 40%.

02

LA-RAG Adaptation for Data-Center Acoustic Monitoring

Adapted and deployed the published LA-RAG architecture for a Cisco data-center use case. The modified system grounds alarm and fan-noise events in time, stores timestamped event records, and retrieves supporting audio evidence for engineer questions over long operational recordings.

03

Graph RAG Agent for PHY/Port Debugging

Modeled Port → PHY → SerDes → ASIC dependencies and combined structured CLI parsing with graph traversal to explain link flaps, CRC bursts, and SFP failures. Reduced average engineer triage time from approximately 60 minutes to 5 minutes for complex PHY faults.

04

AI-Powered Code Review Platform

Built specialized LLM agents for bugs, security, performance, and maintainability, grounded by code knowledge graphs, semantic embeddings, and static-analysis signals. Used confidence-weighted aggregation and developer feedback to improve cross-file reasoning and finding quality.

05

Edge AI Hardware Power Fingerprinting

Learned device-specific signatures from PoE power, current, and voltage telemetry through Cisco IOx and Isolation Forest to detect malicious hardware swaps and automate closed-loop port isolation.

06

Hot-Pluggable Edge Intelligence Platform

Brought up the Robotnik compute module for AI workloads through NFS enablement, containerized deployment, datapath design, resource telemetry, and workload benchmarking on a CN10208-based SONiC platform.

FathomNet Positive-Unlabeled Marine Object Detection
