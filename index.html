Experience & selected projects

01 · Cisco Systems

Graph-Grounded Engineering Intelligence

Built an LLM-driven automated code-review platform in which specialized agents independently inspect pull requests for bugs, security, performance, and maintainability. Code knowledge graphs and semantic embeddings support cross-file reasoning; confidence-weighted aggregation combines agent findings with static-analysis signals, while developer feedback improves ranking over time.

02 · Cisco Systems

PHY and Port Root-Cause Reasoning

Created a Graph RAG agent for link flaps, CRC bursts, and SFP failures across the Port → PHY → SerDes → ASIC dependency chain. TextFSM parses commands such as show interface, show controllers, and show interface transceiver into structured entities; graph traversal and documentation retrieval give the LLM causal context. Average engineer triage time fell from roughly 60 minutes to 5 minutes for complex PHY faults.

03 · OPLUS India R&D

On-Device Generative Vision

Contributed to a Magic Eraser-style mobile feature for intelligent object removal and background synthesis using generative ML models. Also built structured ML failure-detection pipelines and lightweight LLM-assisted log analysis to accelerate diagnosis.

04 · Speech and Language

Event-Grounded Long-Audio QA

Developed LA-RAG, a structured framework for answering questions over multi-hour audio. It converts recordings into timestamped event records, stores them in an event database, and combines intent-aware retrieval with LLM generation. Offline grounding supports low-latency queries, while inference-time grounding supports shorter open-ended clips; evaluations covered Home-IoT, Industrial-IoT, and CASTELLA-QA benchmarks.

05 · Edge AI infrastructure

Robotnik Edge Intelligence Platform

Designed the AI/ML deployment perspective for a hot-pluggable CN10208 SONiC module: DPDK-enabled application processing, resource telemetry, diagnostics, application lifecycle management, boot and image handling, and privacy-aware orchestration on an expanded edge compute complex.

06 · IIT Madras

Spoken Question Answering

Fine-tuned DistilBERT for extractive question answering on SpokenSQuAD, using linear learning-rate decay and automatic mixed precision. Test F1 improved from 52.25 to 54.05.

07 · IIT Madras

Generative Model Evaluation

Implemented and compared DCGAN, WGAN, and ACGAN on CIFAR-10 using FID across 40 epochs. DCGAN achieved the strongest reported FID in the study: 206.19 versus 259.59 for WGAN and 281.99 for ACGAN.
