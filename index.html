Experience & selected projects

Cisco Systems

Agentic systems, network intelligence, engineering AI, and edge platforms.

01

AgenticOps: Autonomous Network Reasoning

Designed and developed a multi-agent AI framework that reasons over network telemetry, topology, logs, configurations, and historical incidents for automated root-cause analysis and remediation planning. Structured state machines decompose incidents into hypotheses, select tools and evidence, and iteratively refine conclusions. Graph RAG models physical and logical dependencies for causal reasoning; relevance-based context selection, intermediate summarization, retrieval filtering, and evidence preservation reduced active token overhead by more than 40%. Monitoring, diagnostic, verification, and remediation agents operate behind policy checks, confidence thresholds, human approval, rollback, and post-action verification. Targeted incident workflows were reduced from approximately 60 minutes to 5 minutes.

02

Event-Grounded Long-Audio QA for Data-Center Operations

Developed an event-grounded question-answering model for Cisco data-center operations running over a UCS switch. The system converts long operational audio into timestamped event records and applies intent-aware retrieval with LLM generation, enabling engineers to query incidents, retrieve relevant temporal evidence, and reason over events in both pre-indexed low-latency and inference-time grounding workflows.

03

Graph RAG for PHY/Port Diagnostics

Built a diagnostic agent for link flaps, CRC bursts, and SFP failures across the Port → PHY → SerDes → ASIC chain. TextFSM transforms show-interface, controller, and transceiver outputs into structured entities; causal graph traversal and retrieved documentation produce evidence-grounded root-cause explanations.

04

Multi-Agent Automated Code Review

Built specialized LLM agents that independently inspect pull requests for bugs, security, performance, and maintainability. Code knowledge graphs and semantic embeddings support cross-file reasoning, while confidence-weighted aggregation combines agent findings with static-analysis signals and developer feedback.

05

AI Hardware Power Fingerprinting

Designed an edge-native device-security pipeline through Cisco IOx and Docker. An unsupervised Isolation Forest learns Layer-1 PoE telemetry patterns—including power, current, and voltage stability—to identify malicious device swaps and trigger closed-loop port isolation.

06

Hot-Pluggable Edge Intelligence Platform

Worked on Robotnik platform bring-up for AI workloads, including NFS filesystem enablement, Docker-supported deployment, datapath design, resource telemetry, and workload benchmarking on a CN10208-based SONiC edge module.
